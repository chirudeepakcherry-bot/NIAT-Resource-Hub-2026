2. Even or Odd - Logic Building

Python Java C 
n = int(input("Enter number: "))
if n % 2 == 0:
    print("Even")
else:
    print("Odd")
import java.util.Scanner;
class Main {
  public static void main(String[] args){
    Scanner sc = new Scanner(System.in);
    int n = sc.nextInt();
    if(n%2==0) System.out.println("Even");
    else System.out.println("Odd");
  }
}
#include 
int main(){
 int n; scanf("%d",&n);
 if(n%2==0) printf("Even");
 else printf("Odd");
 return 0;
}
Logic: The % operator gives the remainder. If a number divided by 2 gives remainder 0, it is Even, otherwise it is Odd.
Q: What does % mean?It is the modulus operator. It returns the remainder after division.
Q: Real-life use case?Used to divide students into groups, check batches, and in game logic.
